# Briefs

Three sectors (local trade, developer tool, one-off event). None comes with photographs; each builder
decides what pictures, if any, the page can honestly carry.

## brief-1 — bicycle repair shop

一頁式首頁，給台南中西區一間開了三十年的單車修理行「阿成單車」。老闆一個人修，只修不賣新車，
週一公休，營業 9:00–19:00，地址在信義街（兌悅門附近）。主要客人是附近騎車通勤的上班族和學生，
最常見的工作是補胎（150 元）、換煞車皮（200 元起）、全車調整（500 元）。希望大家看完知道價錢、
知道什麼時候來、知道可以先 LINE 預約。單檔 HTML。

## brief-2 — CSV diff command-line tool

Landing page for `tabdiff`, a free, open-source command-line tool that compares two CSV files by key
column instead of by line, so reordered rows do not show up as changes. Written in Rust, single binary,
installs with `cargo install tabdiff` or Homebrew. Output modes: a coloured terminal table, JSON, or a
Markdown summary for pull requests. Audience: data engineers and analysts who review data changes in
code review. One primary action: install it. Single HTML file.
