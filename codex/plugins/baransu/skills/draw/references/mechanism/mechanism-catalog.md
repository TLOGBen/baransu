# Mechanism catalog — index of the Anatomy collection

An index of the 52 figure pages in `collection/` (each page vendored verbatim from skills.wheresryan.sh/anatomy/collection, MIT; `collection/INDEX.md` is the source index). Each row links the page and, where one exists, the upstream example source in `../../scripts/anatomy/examples/`.

How to use it: this is the topic `mech-catalog-index`, printed by the step command of `mech-catalog-and-example` before the first anatomy step (`mechanism.md` § The anatomy step table). It is a study of how concepts became objects, not a menu. Read three or four rows near the idea — including its own row when the idea is here — and, for the one whose card is most instructive, its collection page (topic `mech-collection-<page name>`, e.g. `mech-collection-b-tree`: description, readouts, legend, caption, control labels). Then invent your own object (`mechanism.md` § Inventing your own), even when the idea already has a row: a published figure is never redrawn, and an object is never copied from a picture. The finish and the craft may be borrowed; the machine is invented for this request. An upstream example is a source to read for an API the figure needs, not a figure to build first: the closest example is not built or captured by default, and one that is built goes only into `<out>/scratch/` (`mechanism.md` § Study an example).

Columns: **Layer** is how the published figure is drawn (SVG solids only; WebGL adds a shader for fire, water, plasma or light; 3D has parts that really turn). **What moves** is a one-line summary; the collection page holds the full text. **Prompt** is the page's own prompt, verbatim; early examples have none.
