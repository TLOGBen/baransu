# Notice

The idea behind `/lint` — every mistake an agent is caught making becomes a check that makes it impossible, and the checks run at fixed moments rather than from memory — comes from Lauren Tan's account of building a game with an agent (lint rules for each issue found, TLA+ for the game's state machines) and from the `correct` skill in Cursor's pstack plugin ([cursor/plugins](https://github.com/cursor/plugins)), by Lauren Tan, MIT License. No text or code of either is copied; they are credited for the ideas this skill started from.
