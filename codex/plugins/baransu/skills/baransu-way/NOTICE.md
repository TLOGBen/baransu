# Third-party notice — $baransu:baransu-way

`$baransu:baransu-way` takes its outline from the `poteto-mode` skill in Cursor's pstack plugin ([cursor/plugins](https://github.com/cursor/plugins), `pstack/skills/poteto-mode/`, retrieved 2026-10-19), by Lauren Tan, under the MIT License reproduced below.

What was kept, in this skill's own words: a fixed set of things every run does; a principle list where each entry says when it applies and the reply names the principle that shaped each decision; classifying a fork before asking, so a question a run could settle is not put to the user; owning each delegated result rather than passing its report through; routes copied into the task list with a skip reason for each step not run; and grounding through `how` and `why` before a route starts. What changed: there is one entry with no persona, model table, or subagent defaults; the principles are this repo's review principles instead of a separate principle library; routes run baransu skills; autonomy is the loop contract's standing authorization with each skill's own pause table, not session overrides; a ledger on disk carries a chained run across turns; and a chain stops only for the five stops named in the skill. No upstream file is copied.
