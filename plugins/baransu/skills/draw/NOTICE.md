# Third-party notices — /baransu:draw

`/draw` bundles material from the projects below so that it works with no network access and no other skill installed. Each project's license file is kept beside its material. Modifications are limited to the path rewrites listed here (verifiers moved under `scripts/diagram/repo/`, the upstream `test-verify-*` harness omitted, the `taste-gate.md` checklist re-homed from the upstream SKILL.md, the Anatomy `SKILL.md` renamed to `ANATOMY-SKILL.md`) and one safety patch: every vendored script that starts Chromium seeds its temporary profile's `Local State` with a recorded password check before launch (Archify `scripts/map/bin/visual-check.mjs`, diagram `scripts/diagram/repo/lint-render.py` and the PNG rasterize snippet in `references/diagram/export.md`, Anatomy `scripts/capture.mjs`, `drive.mjs`, `turn-check.mjs`). On a Windows machine outside a domain, Chromium otherwise calls `LogonUser(user, ".", "")` the first time a fresh profile opens a tab, to learn whether the account has a blank password; each call is a failed interactive logon (event 4625), and ten in the lockout window lock the user's Windows account. Each patched line is marked `/draw:`; no upstream rule was changed. Where `/draw` runs a vendored skill differently, the override lives in a draw file and is listed here; the upstream file stays as published.
