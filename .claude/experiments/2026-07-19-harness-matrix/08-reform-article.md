# 雙塔換雙釘——十格實驗之後的改革設計

第一輪實驗把十組配置送上盲評法庭，判出了冠軍和墊底。判決落定之後，一個更難的問題浮出來：被告 analyze 與 execute 是在設計射程之外受審的——它們生來是為跨系統、跨 session、E2E 收斂的大型戰場造的，實驗卻拿三個單 session 收得掉的中型任務量刑。這一冊記錄改革怎麼從這個張力裡長出來。

## Skill 的解剖：三種假肢

把兩個 skill 拆開看，它們其實同時承載三種假肢，實驗給了三種不同的判決。知識假肢——怎麼分析、怎麼測試先行、陷阱長什麼樣——十組的規格作者全部自己推導出來，這部分已經內化進模型，可以蒸發。流程假肢——五層文件、逐任務上下文檔、Red gate 儀式、DAG 編排——在實驗裡零測量效果，退役。注意力假肢——「現在該把陷阱寫成條文了」「收尾前該開審查了」——正是模型還做不到的事：p1-f 知道 idx 陷阱，測試 fixture 全用非連續索引，卻在寫 CLI 訊息那一刻沒想起來。這不是知識缺口，是時機缺口。

結論跟著出來：skill 不會死，但身分要換。它的殘餘本體是「在正確時機喚起正確行為」的具名觸發點——一個注意力假肢，內容物從四百行流程縮到二三十行。

## 雙塔換雙釘：contract 與 seal

改革的落點是兩個微型 skill。`/contract` 取代 analyze：動手前先產出一頁合約——每條驗收條文具名可斷言、使用者可見文字給精確格式或禁止清單、錯不起的表面逐列配釘死測試、固定常數照抄不重打。`/seal` 取代 execute：宣告完成前開一個乾淨 context 的審查者，帶五行任務書——逐條驗收、掃無測試釘住的表面、跨端一致性、常數逐字比對、殺不死突變就打槍。

支撐這個設計的是實驗最硬的一條因果鏈：六個引入 bug 裡五個是同一類（把不連續索引加一當章數印給使用者），而擋住它的三組各用一招——警語靠運氣、精確格式靠結構、死條文加審查靠授權。一頁合約把後兩招制度化，一次 seal 把第三招的成本從八個 agent 壓到一個。

## 尺度外推:跨系統與 SA 文件情境

雙塔的設計射程要另外處理。跨系統情境裡，舊失敗模式全部升維：責任稀釋變成「兩側 mock 互相同意、卻都不同意現實」；常數轉抄變成 schema 靜默漂移；再加三個新怪物——context rot 讓外部記憶從冗餘變成腦本身、E2E 的分鐘級回饋摧毀突變紀律、部署時序帶來全新的相容性條文類別。

一頁紙在這裡不塞爆，它分形。關鍵換座標：系統間邊界就是彼此的 user-facing 表面，「使用者」是對面那個系統。於是總合約管邊界（wire format、錯誤語意、相容矩陣），固定常數升格為兩側都 import 的共享 schema 工件，每側各持一頁子合約，審查分工成每側的 sealer 加一個只管邊界的所有人。E2E 縮到三五條 smoke 路徑，信任壓給契約測試層。

最日常的版本是「完成一個前後端整頁功能、對 SA 文件宣稱完成」。SA 文件天生是鬆條文——「頁面應顯示會員等級」沒有一個字能拿來打槍，所以「宣稱完成」是一個不可證偽的修辭動作，驗收會議必然變成解釋學辯論。改革在這裡加一個 ingestion 階段：實作前先把 SA 文件逐句翻譯——可斷言的進合約、藏隱性需求的補條文或明文排除、翻譯不了的退回 SA 當 OPEN QUESTION。宣稱完成從一句話換成一包證據：條文對測試對綠燈、表面四態對截圖、schema 零漂移證明。歧義的成本從最貴的驗收日搬到最便宜的開工前。

## 三頻段路由與裸跑的價值

把射程問題畫成路由表：小任務直接做；中頻段（單 session、跨數模組）走 contract 加 seal；大頻段（跨 session、跨系統、E2E）走改革後的雙塔——分形合約、邊界所有人、編排機械復役。中頻段有本輪實驗定讞，大頻段標註外推、等第三輪雙系統實驗補判。

裸跑在這張圖裡不是缺席的方法，是自帶性質的方法。它是量尺：沒有 $4.92 的對照組，模型原生就會的東西全會記進流程的功勞簿。它有結構防護：四大失敗模式裡的轉抄鏈和責任稀釋，在單一心智全責下根本不存在。它是校準儀：模型每換一代，定期裸跑是唯一能測出「又內化了什麼、哪些鷹架該拆」的儀器——不做定期裸跑的 plugin 必然單調增肥，因為減法永遠拿不到證據。

## 選用會不會選對

誠實答案是不會總是選對，而且無法讓它總是選對——選用是模型讀 description 做的語意判斷。改革的解法是換目標：不追求選得準，追求選錯很便宜、選漏抓得到。微型化讓誤觸發從三十分鐘變兩分鐘；觸發條件改寫成可觀測特徵（跨 session？碰 user-facing 表面？）而非模糊尺寸；seal 改成預設開啟、配一個機械 hook 偵測「diff 碰了表面卻沒 seal」；頻段詞彙縮到三個詞讓人腦直接路由。最後把選用決策納入遙測，誤觸發率按月回看、餵給演化迴圈修 description——路由的正確率是量出來修出來的，不是設計出來的。

## 驗證輪：最大膽的舉動、最小心的測試

改革不空談，三個驗證 arm 已在原基線上開跑：p2-os′ 測改革後規格的純前饋上限；p3-os′ 測死條文加窄域審查能否讓原墊底配置翻身追平冠軍；p-min 直接下注無 skill 世界——Opus 一頁合約、Sonnet 實作、Opus 單次審查，三個 agent 零管線。事前預測已落筆：p3-os′ 該到 20/21 零缺陷，p-min 若摸到同級分數且成本壓在冠軍四成以下，「skill 退役成一頁紙加一次呼叫」就從激進猜想升格為實測配置。同一份簡報、同一個基線、同一套盲評，結果出爐即回填本冊。
