# reason record — why a part was not formalized

(unimplemented) Intent: the one schema for every unformalized part — in a hypothesis README, and in a `/hunt` case file or `/review` output when a trigger row matched and no hypothesis was written. Those skills cite this file; they never restate it.

## Fields

(unimplemented) Four columns, all required:
- **哪一段** — a citation in its source's form, or the claim verbatim
- **原因** — exactly one class from the list below
- **具體情況** — what the class needs named (the missing tool, the dependency, the bound tried and how long, the non-trigger row, the person's words)
- **要什麼才能形式化／現在改走** — the condition, and the route now: hunt 推測, 紅綠測試, or 不處理

## Classes

(unimplemented) 沒有工具 · 無法建模 · 超出範圍 · 符合不觸發條件 · 沒有對錯可證 · 使用者決定不做. "adapter not admitted" is 沒有工具.
