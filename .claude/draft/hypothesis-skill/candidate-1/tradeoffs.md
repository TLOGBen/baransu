# tradeoffs — 我們接受 X，換到 Y

1. **我們接受讀者要跑一支 Python 腳本**（多一個檔案要寫、要在 Codex 鏡像找得到路徑；hunt 的 `hunt-search.py` 已經是同一種依賴），**換到讀者不需要知道** README 格式、同步點有幾種、舊位置在哪、TLC 怎麼叫——五個讀者裡任何一個都不用重寫一次過期判斷。刪掉腳本的話，這段複雜度會在五個讀者身上各長一次（structure.md #5 的刪除測試）。

2. **我們接受同步點統一成 blob hash、commit 只當 diff 起點**，**換到程式與文件同一套過期判斷**，而且在有未 commit 改動的工作區寫的假說也精確。代價：`sync` commit 被 rebase、squash 掉之後，`--maintain` 沒有 diff 起點，只能把模型和現在的來源整份重讀一次。

3. **我們接受輸入種類由 skill 自己猜，偶爾猜錯**（一份 `.md` 是程式說明還是需求文件？），**換到使用者只要記一個指令、零個種類旗標**。猜的結果一定在第一行說出來，使用者可以一句話更正。

4. **我們接受 `--maintain` 由「涵蓋的 area 過期」自動開啟**，**換到使用者不必記得什麼時候要維護**。旗標保留只因為 `_shared/auto-flags.md` 規定旗標不能是唯一入口。

5. **我們接受 README front matter 只能用 YAML 子集**（純量和單行純量清單，不能巢狀），**換到標準函式庫就能解析**，不用 pyyaml，也不用 Python 3.11 的 tomllib。規則、發現在 front matter 裡只有一行摘要，細節放在正文。

6. **我們接受每條規則各一個檢查**（TLC 碰到第一個違反就停，三條 bug 要三次跑），**換到每條規則各有自己的判定**，讀者看得到「R2 不成立、其他成立」而不是一個籠統的失敗。

7. **我們接受不建總表**，**換到沒有清單會跟目錄脫節**。代價是每次 status 都要 glob 一次；area 數量是個位數到幾十，可以忽略。

8. **我們接受讀者只看得到腳本印出的東西和 README 的 `## 發現`**，**換到 README 其他章節（對照表、範圍、維護紀錄）可以隨時改格式**而不會弄壞任何讀者。

9. **我們接受寫入要先寫草稿再交換**（Windows 上目錄不能 rename 蓋過，要三步），**換到停在任何一步都不會出現新舊混合的 area**，同步點也不可能在關卡通過前往前移。

10. **我們接受「無法寫成」不擋紅綠的綠燈**（exit 0），**換到一份誠實說「這裡沒辦法形式化」的假說不會讓每次改動都卡住**。它的那一行照樣印出來，原因紀錄也在。

11. **我們接受圖頁從 CDN 載入釘死版本的 Mermaid**，**換到不用打包任何前端資源**。離線時每張圖下面的文字版照樣能讀。

12. **我們接受讀者在「使用者說不要寫」時自己寫一行原因紀錄**（唯一一個讀者需要懂的格式），**換到其他所有「沒形式化」都集中由 `/hypothesis` 寫成 `cannot` area**，下次觸發時看得到上次為什麼沒寫、條件變了沒。

## 考慮過、丟掉的做法

- **讀者各自讀一份 `references/reading.md`，自己算過期**：五份實作，第一個漂移的就會在過期時報通過——正是計畫決策 4 要用結構擋掉的事。
- **README 裡寫好一行檢查指令，讀者照抄執行**：讀者執行檔案裡的字串，等於讓 repo 裡的資料決定跑什麼程式；而且 pwsh、Git Bash、zsh 的引號規則各不同。
- **`hypothesis.json`（給機器）加 README（給人）兩份檔**：同一份規則寫兩次，一定會不同步。
- **TOML front matter**：解析要 Python 3.11+，而且 repo 其他地方全是 YAML front matter。
- **腳本負責產生 README 和圖頁**：圖組要判斷哪個元件先加、標籤怎麼寫，那是模型的判斷力，不是固定程式；腳本會長成一個前端產生器。
- **`/hypothesis write`、`/hypothesis doc`、`/hypothesis maintain` 三個子指令**：使用者得先分類自己的輸入，分類錯了還要重來；skill 自己判斷比較便宜。
- **把 `status`、`check` 做成 `/hypothesis` 的旗標**：讀者叫起寫入者，只讀就變成靠紀律；而且每次查詢都要載入整份 SKILL.md。
- **把過期旗標存進 README**：需要有人在每次程式改動時更新它，那正是會被忘記的事。
- **一個總的 `.claude/hypothesis/index.md`**：prove-it 的 recipe 今天就要手動列形式檢查，這是另一份會脫節的清單。
