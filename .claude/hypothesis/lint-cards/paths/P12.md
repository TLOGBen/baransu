# P12 — E8、E11：刪除預覽設成 `warn`、`info`、`retry` 時，第一次就畫成純文字並叫你「再下一次」

害處：把刪除預覽調成只提醒、不擋（`format.md` 允許）之後，指令第一次就執行了，卡片卻寫「確定沒錯，再下一次同樣的指令」，而且是純文字。

（檢查器 `pre:bash delete warn`、`delete info`、`delete retry` 判出；第二推導第 4(b) 項找到 E11，它用的 message 不是 preset 的，所以沒看到 E8。）

1. `destructive-preview` 改成 `warn`（或 `info`、`retry`），`message` 用 preset 的原文。
2. `rm -rf build`：`settle` 給 `gate = 'pass'`，指令直接執行，預覽那條發現進 `inline`。
3. 動作之後 `keepCard(S(), e.id, summarize(..., inline))`：沒有 `paths`，預覽和 message 畫成一行文字。

結果：已執行的呼叫底下，寫著「再下一次同樣的指令」的純文字卡片。

根源：放行的路徑不轉路徑清單（同 P11）；preset 的 message 是照 `check`（會擋一次）寫的，等級一改，這句話就不成立。
