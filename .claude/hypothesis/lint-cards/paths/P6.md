# P6 — E7（W2）：輸入框上方被問卷佔著時，卡片沒畫也沒送文字

害處：Claude Code 跳出問卷（survey）時，這段期間的 lint 結果你完全看不到。

1. 你開著桌面版，`$.session.surfaces()` 回傳 `['desktop']`。
2. 一輪要結束被擋下，`engine.ts` 的 `stopping` 經過 `post`，把卡片放進 band，再呼叫 `view/port.ts` 的 `show`。
3. `show` 看到有能畫輸入框上方那條的畫面，就不送文字。
4. 畫面要畫輸入框上方時，`hasSurvey` 是 true，`view/hooks.ts` 的 `AbovePrompt` hook 讓給問卷（`next(e)`），卡片沒畫出來。

結果：卡片既沒畫出來，也沒有改送文字（檢查器「E7 (W2)」）。

根源：`show` 決定要不要改送文字的當下，不知道那條會被問卷佔住；平台規定 AbovePrompt 的 hook 要讓給問卷（`AbovePrompt.hasSurvey`：「a hook yields to it」）。
