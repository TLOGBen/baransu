# P9 — E5：只貼圖片、沒打字的訊息，不會清掉上一則的卡片

害處：你只貼一張截圖送出時，輸入框上方還留著上一則訊息的 lint 卡片，看起來像是這次的結果。

（第二推導 E5-a 找到；檢查器「E5 a message of only an image」在真程式上確認。）

1. 輸入框上方有一張卡片。
2. 你只貼一張圖送出，文字是空的 → `prompt.submit` → `adapters/claude-code/translate.ts` 的 `promptEvent`：`!String(a.text ?? '').trim()` 成立，回傳 `null`。
3. `adapters/claude-code/hooks.ts` 的 `prompt.submit` hook 看到 `null` 就直接 `next(e)`，沒有進到 `promptSubmit`，所以清 band 那行沒有執行。

結果：上一則的卡片還在。

根源：「這是不是你送出的一則訊息」和「這則訊息有沒有文字讓 lint 讀」被同一個判斷綁在一起。
