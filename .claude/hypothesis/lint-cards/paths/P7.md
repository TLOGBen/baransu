# P7 — E7（W3）：同時開著終端機和手機，手機看不到沒有呼叫的卡片

害處：你在手機上跟著同一個 session 時，一輪被擋下、外部改檔這類卡片只出現在終端機，手機上什麼都沒有。

1. session 同時接著終端機和手機，`$.session.surfaces()` 回傳 `['terminal', 'mobile']`。
2. 一輪要結束被擋下，卡片經過 `post` 放進 band，再呼叫 `view/port.ts` 的 `show`。
3. `show` 只要看到有任何一個畫面能畫輸入框上方那條（這裡是終端機），就不送文字。
4. 手機不會觸發 `AbovePrompt`（平台說明：「Raised on the terminal and desktop surfaces only」），所以手機上看不到卡片，也沒有文字。

結果：手機上看不到（檢查器「E7 (W3)」）。

根源：`show` 判斷的是「有沒有任何一個畫面能畫」，不是「每個畫面都能畫」。改成後者的代價是：終端機會同時看到卡片和那一行文字。
